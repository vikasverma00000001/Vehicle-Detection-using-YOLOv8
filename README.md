*** Project Overview

Vehicle Detection Using YOLOv8 is a computer vision project that detects vehicles in images and videos using the YOLOv8 (You Only Look Once) object detection model.

The project can be used for traffic monitoring, vehicle surveillance, road safety, and intelligent transportation systems

*** Technologies Used
Python
YOLOv8
Ultralytics
OpenCV
Google Colab
PyTorch
Roboflow

***Project Workflow
Set up the Python environment.
Install YOLOv8 and its dependencies.
Download Roboflow the vehicle detection dataset.
Organize the dataset into training, validation, and test sets.
Configure the dataset using a data.yaml file.
Train the YOLOv8 model.
Evaluate the model using precision, recall, and mAP.
Run predictions on images and videos.
Save the trained weights as best.pt.Ro
